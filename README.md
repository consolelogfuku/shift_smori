# シフト (shift_smori)

月曜から金曜に営業する事業所向けの、月単位のシフト作成ツールです。
30 人規模の従業員に対して、役割要件、出勤人数、同日 NG の組み合わせ、希望休を満たす割り当てを数秒で作り、Excel / CSV に出力します。

## 設計方針

- **サーバーに個人情報を置かない。** 完全にブラウザ内で動く静的サイトです。データはブラウザの localStorage にだけ保存され、利用者が決めた合言葉で暗号化されます (AES-GCM 256、PBKDF2-SHA256)。開くたびに合言葉が必要です。「保存する」で JSON ファイルとして利用者の PC に書き出し (こちらは平文)、「読み込む」で復元します。
- **割り当てはロジックで計算する。** LLM は使いません。貪欲法で初期解を作り、焼きなまし法で制約違反のペナルティを最小化します (`src/solver/`)。計算は Web Worker 上で行います。
- **祝日は自動判定。** `@holiday-jp/holiday_jp` で日本の祝日を判定し、年末年始などの休業日はカレンダー上で月ごとに指定します。

## 画面

サイドバーの項目ごとに 1 画面 1 目的です。

1. **初期設定**
   - 従業員を登録: 一覧、追加、編集、削除、Excel からの一括取り込み (氏名 1 列のフォーマットをダウンロードして記入し、ドラッグ＆ドロップ)
   - 役割: 一覧、追加、編集、削除 (郵送事務、電子申請、電話対応など)
   - 勤務時間: 一覧、追加、編集、削除 (A勤務 9:00-17:00 など)
   - 従業員と役割の紐付け: 従業員 × 役割のチェック表
   - 従業員と勤務時間の紐付け: 従業員ごとに勤務時間を選ぶ (未設定の人への一括設定つき)
   - この役割の人は毎日最低何人必要か: 郵送事務 1 人、受付 2 人など。合計がその日の出勤人数
   - 同じ日に出勤させない従業員の組み合わせ
2. **シフトを組む** (月を選んで 4 ステップ)
   - STEP1 営業所の休業日を登録: カレンダーの日付をクリック
   - STEP2 有給・出勤希望日を登録: 従業員 × 日の表でセルをクリックし、有給 (終日)、有給 (時間休、5 分単位の時間帯)、希望出勤日を選ぶ
   - STEP3 必要な役割を調整: 日付をクリックしてその日だけ役割の人数を増減
   - STEP4 シフトを組む: 条件の確認と実行。同じ画面に結果 (守れなかった条件、人 × 日の表、セルをクリックで手直し) が出て、Excel / CSV で出力。気に入らなければ「組み直す」

## 制約の扱い

| 条件 | 種類 |
| --- | --- |
| 有給 (終日) の日に出勤しない | ハード |
| 希望出勤日 (時間休の日を含む) に出勤する | ハード |
| 同じ日に出勤させない組 | ハード |
| 日ごとの出勤人数 (= 役割の必要人数の合計) | ハード |
| 役割ごとの必要人数を、その役割を持つ出勤者で埋める (1 人 1 枠) | ハード |
| 人ごとの月の出勤日数 (未指定なら均等配分) | ソフト |


## 開発

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # vitest (ソルバー・出力・取り込み)
npm run build    # dist/ に静的ファイルを出力
```

## デプロイ (Cloudflare Workers, 静的アセット)

`wrangler.jsonc` で `dist/` を静的アセットとして配信する設定になっています。サーバー側のコードはありません。

```bash
npx wrangler login
npm run deploy
```

```jsonc

  "version": 1,
  "settings": {

    "workPatterns": [{ "id": "...", "name": "A勤務", "start": "09:00", "end": "17:00" }],
    "employees": [{ "id": "...", "name": "森 花子", "skillIds": ["..."], "workPatternId": "...", "monthlyWorkDays": null }],
    "conflictPairs": [{ "id": "...", "a": "...", "b": "..." }],

```

## 従業員の一括取り込み形式

「従業員登録フォーマットをダウンロード」で得られる Excel は氏名の 1 列だけです。2 行目から 1 行に 1 人ずつ氏名を書きます。CSV でも 1 列目を氏名として読みます。役割と勤務時間は取り込み後に「従業員と役割の紐付け」「従業員と勤務時間の紐付け」で設定します。
